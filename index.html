About the project

A restaurant idea built for school.

Ronaldo's Buffet is a fictional restaurant concept. The website is designed to demonstrate HTML, CSS, JavaScript, forms, responsive design, and interactive website features.

🍽️ The Concept

A fictional buffet combining Chinese-inspired dishes with chorizo specials. Customers choose the number of plates they want, and the project calculates the example price.

💻 The Website

This project includes a responsive menu, pricing system, automatic business hours, forms, FAQ, sample reviews, and interactive JavaScript features.

FAQ

Frequently asked questions

Is Ronaldo's Buffet a real restaurant?

No. Ronaldo's Buffet is a fictional restaurant website created as a school project.

Can I actually place an order?

No. The takeout system is an interactive demonstration. It does not send an actual order or charge money.

Are the prices real?

No. The prices are example prices created for this project and can be changed in the JavaScript.

Why does the website say Open or Closed?

JavaScript checks the visitor's current browser day and time and compares it with the example hours configured in the project.

Are the reviews real?

No. The reviews are clearly labeled as sample reviews because this is a school project.

Can the prices be changed?

Yes. The prices are stored in one JavaScript array, making them easy to edit.
